◈ YOUR WEBSITE IS ON WIX, AND WHAT THAT CHANGES

While I was in your GoDaddy account I found that rufcollc.com is not being served from GoDaddy at all. It is on Wix, a different company entirely. The GoDaddy hosting you pay for is sitting almost empty next to it. You asked what our options look like if we get the Wix login and dig in. Here is the honest answer.

Getting the Wix login does not add a fourth option
Wix builds and hosts websites. It is not a place a custom program with its own database can live. This decision does not change either way.

Wix is a website builder, the same category as GoDaddy's own website builder. It is very good at what it does. You point and click, it produces a website, and Wix runs it for you. What it does not do is let somebody build a full custom application on top of it. Wix has a coding feature for adding small pieces of behavior to a Wix site, and it comes with hard limits on how much work it will let that code do, plus limits on how much data it will store. RoofCommand is a real program with a real database behind it. That is a different thing than a website, and Wix is not built to hold it.

So the Wix question is not a hosting question. It is an ownership question about your public website, and it still needs an answer.
